The five PNGs are unchanged embedded images from the owner-supplied

the deck hash, actual slide numbers, package members, dimensions and image hashes.

the HCP/Melbourne meshes. Source highlighting is not the atlas colour legend.

ventricular or nuclear meshes in the viewer. Exact collection accession IDs
were not supplied; the provenance locator is the deck package member.

specified attribution and retained watermarks. Hodos retains that credit beside

Hodos MIT license; this educational distribution preserves their original terms.

## Caption evidence

- Source photographs and the supplied deck establish the depicted dissection
  views, original highlights and the local source selection.
- Kier et al., 2004 (PMID 15140705), already cited as R3 in Hodos, supports the
  relative temporal-stem courses of UF, IFOF and optic radiation. It is an
  independent anatomical reference, not a claim that these are its figures.
- Captions require orientation and trajectory comparison before functional
  inference. They do not import the deck’s categorical surgical shorthand.

The reference component lazy-loads only the selected photograph. The enlarged
view reuses its source URL. The five originals total about 13.6 MB; no picture
requests are needed at library entry or in unrelated relationships.
