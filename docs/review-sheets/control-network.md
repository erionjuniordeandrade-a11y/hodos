# The control network: SLF II and the frontoparietal system

Lesson id: `control-network` · Minutes: 15 · Review status: draft

**Summary:** Relate frontoparietal control evidence to lateral prefrontal and parietal atlas references. Compare the SLF II population sample with neighbouring SLF families while keeping network, parcel and task evidence separate.

**Goals:**
  - Distinguish the Yeo-7 FPN partition from study-specific executive-control systems.
  - Locate lateral prefrontal and parietal HCP-MMP1 reference parcels.
  - Compare SLF II with neighbouring SLF I and SLF III samples without inferring individual function or connectivity.

**Audience:** Neurosurgical residents

## Opening question

Which task evidence is needed to assess executive control beyond motor and language observations?

## Three takeaways

1. Name the task demand and the evidence used to assess it. _(step 0: Start with the control demand)_
2. Keep the FPN wash, parcel pointers and SLF II sample distinct. _(step 4: Follow the lateral white-matter sample)_
3. Describe the additional task demand and the behavioural evidence used to assess it. _(step 6: Ask what a bedside screen leaves open)_

## Steps

### Step 0: Start with the control demand

**Claim:** Frontoparietal control is studied in relation to demands such as holding information, maintaining a goal and adapting to changing tasks. These demands come from cognitive-control research; this population scene can orient a network discussion but cannot measure a person’s function.

**Observe:** Show the FPN wash in the left lateral view. Select areas 46 and 9-46d, then compare them with IP2 and IP1. Read the wash as a group network partition.

**Anatomy:**
  - Intrinsic-connectivity research describes a distributed frontoparietal control system.
  - Multi-task connectivity studies examine flexible network participation during adaptive control.
  - A meta-analysis relates cognitive control to several executive functions; no single scene item measures them.
  - Middle-frontal areas 46 and 9-46d lie anterior to intraparietal parcels IP2 and IP1 on the lateral surface.

**Surgical:** In a resident discussion, name the task demand and the observed performance separately from the atlas network label. The Hodos scene provides population orientation, not an individual functional result or a measure of surgical safety.

**Question:** In the left lateral view, how do middle-frontal 46 and 9-46d relate spatially to intraparietal IP2 and IP1?

**Answer:** Areas 46 and 9-46d occupy lateral middle-frontal territory anterior to the intraparietal IP2 and IP1 references. The FPN wash is a population partition, so this spatial arrangement does not establish an individual executive map.

## Full source list

- **CN1** — Vincent et al., 2008 · frontoparietal control system (PMID 18799601) — functional_measurement
  - _Scope:_ Intrinsic functional connectivity supports a distributed frontoparietal control system in the studied groups. It does not supply an individual task map or patient-specific boundary.
- **CN2** — Cole et al., 2013 · flexible hubs for adaptive task control (PMID 23892552) — functional_measurement
  - _Scope:_ Multi-task connectivity supports flexible frontoparietal hub participation across adaptive control demands. It does not assign one fixed operation to a parcel or tract.
- **CN3** — Niendam et al., 2012 · cognitive control network meta-analysis (PMID 22282036) — functional_measurement
  - _Scope:_ The meta-analysis relates a superordinate cognitive-control network to diverse executive functions. It does not localise an individual deficit or establish whether a particular assessment covered every executive demand.
- **D1** — Van Essen et al., 2013 · the WU-Minn Human Connectome Project overview (PMID 23684880) — atlas
  - _Scope:_ Provenance for the S1200 group-average surface rendered here. A group-average midthickness surface is a population object; individual gyral and sulcal anatomy differs from it.
- **M1** — Glasser et al., 2016 · multi-modal parcellation of human cerebral cortex (PMID 27437579) — atlas
  - _Scope:_ HCP population reference built from converging cortical features. A parcel boundary here is a group boundary; it does not locate one person’s functional border and it has not been registered to any individual in this viewer.
- **N1** — Yeo et al., 2011 · intrinsic cortical network organization (PMID 21653723) — atlas
  - _Scope:_ Resting-state fMRI in 1,000 adults. Source of the installed seven-network cortical partition; no individual task activation or subcortical network map is supplied.
- **N13** — Dosenbach et al., 2007 · adaptive and stable task control (PMID 17576922) — functional_measurement
  - _Scope:_ Task-response patterns and resting-state connectivity motivated distinct frontoparietal and cingulo-opercular control systems. Network definitions and proposed timescales belong to that analysis.
- **N11** — Seeley et al., 2007 · salience and executive-control networks (PMID 17329432) — association
  - _Scope:_ Task-free connectivity separated a frontoinsular/dorsal-cingulate network from a lateral frontoparietal control network. This is a different definition from the coarse Yeo-7 ventral-attention partition.
- **D2** — Yeh, 2022 · population-based tract-to-region connectome of the human brain (PMID 35995773) — atlas
  - _Scope:_ Provenance for the HCP1065 population-averaged bundles rendered here. Every displayed line is an average-space reconstruction sampled for display; it is not a patient’s pathway and carries no direction of conduction.
- **CN4** — Parlatini et al., 2017 · Functional segregation and integration within fronto-parietal networks (PMID 27639357) — association
  - _Scope:_ SLF tractography in 129 participants combined with 14 fMRI meta-analyses associated a dorsal spatial/motor network with SLF I and a ventral non-spatial/motor network with SLF III; all investigated functions activated a middle network mostly associated with SLF II. These group associations do not establish an exclusive connection for the Yeo-7 FPN.
