# Review sheets

Generated. Every `*.md` file in this directory except this README is produced by
`npm run review-sheets` (`scripts/review-sheets.mjs`) from the live `viewer/lesson_content.js`,
`viewer/lesson_briefings.js` and `viewer/case_content.js` modules — one sheet per lesson and
per fictional case (18 total), for the owner's Phase 0 review pass
(`docs/plans/2026-09-25-teach-back-program.md` §3, unit 0.1). Do not hand-edit the generated
files; re-run the script instead. `docs/` is tracked (not gitignored), so these files commit
like any other doc.
