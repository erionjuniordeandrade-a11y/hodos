# Default mode network · hubs, subsystems & connections

Lesson id: `default-mode-network` · Minutes: 18 · Review status: draft

## Opening question

Motor examination and conversation seem preserved, but recalling familiar events is difficult. What further anatomical account is needed?

## Three takeaways

1. Orient anterior medial, posterior cingulate and retrosplenial references. _(step 1: Orient the anterior and posterior medial references)_
2. Compare cingulum trajectories with functional coupling without equating them. _(step 2: Compare cingulum anatomy with functional coupling)_
3. Relate medial-temporal anatomy to a specific cognitive operation rather than a broad network label. _(step 3: Separate the medial-temporal subsystem from the wider network)_

## Steps

### Step 0: Find a distributed network across the medial and lateral surfaces

**Claim:** The default mode network includes separated medial prefrontal, posterior medial and lateral parietal territories. Begin by following the red Yeo-7 wash around the surface, rather than looking for one central structure.

### Step 3: Separate the medial-temporal subsystem from the wider network

**Claim:** The default network has internal structure. One studied component relates medial temporal, retrosplenial and posterior parietal regions; another relates dorsomedial prefrontal and lateral temporal/parietal regions.

### Step 4: Understand “default” without calling the brain inactive

**Claim:** The term arose from reproducible changes relative to baseline during tasks. It does not mean the network operates only when a person is doing nothing; internally directed cognition can itself be an active task.

**Sources:**
